First launch. RNAflow offers to install everything it needs (conda and the analysis tools, about 400 MB) into ~/.rnaflow. It does not need an administrator password and does not change your shell settings.
macOS says "RNAflow is damaged"? Open Terminal and run xattr -cr /Applications/RNAflow.app, then open the app again.
Windows. The analysis tools come from Bioconda, which needs Linux, so on Windows they run inside WSL2. The app shows the steps.
ManualEvery step explained, with what good output looks like. ChangelogWhat changed in each release. How to citeDOI and reference for your methods section. All releasesEarlier versions and checksums on GitHub.

Prefer not to install an app? RNAflow is also one HTML file plus a small Python server with no dependencies. See rnaflow.bioinfocodex.com.
