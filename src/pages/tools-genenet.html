Features

👥
Team Management
Invite members by email with unique invite codes. Admins can block, remove, or restore access per user at any time.
📜
Audit Trail
Every create, edit and delete is recorded with who did it, when, and what the value was before. Each record shows its own history.
🛡️
Admin Control Panel
View all team members, change roles, block or remove users, and manage connection codes from one page.
☁️
Cloud Folder for Files & Backups
Uploads and backups can live in OneDrive, Google Drive or a network share, so they leave the machine on their own. The live database stays on local disk, where it belongs.
📧
Email Invites
Admins send invite emails with a one-click registration link. New users land on a pre-filled form — no code typing needed.
🔒
Access States
Users can be Active, Blocked (temporary), or Removed. Blocked users see a clear message to contact the administrator.

What it costs

Free, and yours

GeneNet runs on your own hardware, with no seat limit and no licence to renew. There is a team size setting so an admin does not accidentally invite more people than they meant to — a guardrail you set yourself, not a paywall.

We fund the work through setup help, hosting and support rather than per-seat licensing. If your lab wants a hand installing it, moving existing records across, or keeping it running, get in touch →

How it works

1
Install the app for your operating system. On first run, the admin completes a one-time setup wizard.
2
Admin invites team members by email from the Team & Seats panel. Each invite generates a unique registration link.
3
Members connect using the LAB-XXXXX connection code (e.g. LAB-84921) and register with their invite code.
4
Admin manages access from the Admin Panel — block, remove, restore, or promote any user at any time.
5
Everything is recorded from then on — every change, who made it and what it said before, with signatures on procedures and reports.
