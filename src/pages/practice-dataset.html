Run an RNA-seq analysis with a known answer

Reading about a pipeline is not the same as running one. This page gives you a small public dataset whose result is well established, so you can check your own analysis against it.

The dataset

The airway study (GEO series GSE52778; Himes et al., 2014) sequenced human airway smooth-muscle cells from four donors, each with and without the glucocorticoid dexamethasone. It is the dataset behind the Bioconductor airway package and one of the most re-analysed RNA-seq experiments, which makes it a good first target.

  • Question: which genes change when the cells are treated with dexamethasone?
  • Design: 4 donors × 2 conditions = 8 samples, paired-end reads. Each donor has both conditions, so this is a paired design.
  • Organism: human.

The GEO series also contains albuterol-treated samples. Use only the eight runs above.

Size. The full FASTQ files for eight human samples take tens of gigabytes and several hours on a laptop. For practice, a subset of a few million read pairs per sample is enough to recover the main result. RNAflow's own benchmark uses 4 million read pairs per sample; its benchmark folder has the script that fetches that subset.

Option 1: with RNAflow

  1. Install RNAflow and let it set up its tools on first launch.
  2. Start a project with Human as the organism, and import the samples by pasting the accession GSE52778. Keep the eight runs in the table.
  3. Set the two conditions (untreated and dexamethasone) and use a paired design, with the donor as the pairing factor.
  4. Follow the steps in order. The manual explains what each one does and what good output looks like.

Option 2: on the command line

Download the reads with sra-tools, then follow the RNA-seq module step by step.

mkdir -p airway/raw && cd airway for run in SRR1039508 SRR1039509 SRR1039512 SRR1039513 \ SRR1039516 SRR1039517 SRR1039520 SRR1039521; do fasterq-dump "$run" --split-files --outdir raw --progress done gzip raw/*.fastq

The RNA-seq cheat sheet has the commands for the steps that follow.

What you should find

Dexamethasone switches on a well-known set of glucocorticoid-response genes. All seven of these should be significantly up-regulated in your result:

DUSP1 FKBP5 KLF15 PER1 TSC22D3 ZBTB16 CRISPLD2

Check your work

  • Alignment or mapping rate is high (above about 90% for this dataset).
  • In the PCA plot, samples separate by treatment once the donor effect is accounted for.
  • The seven genes above appear among the up-regulated genes.
  • You can say, in one sentence, why a paired design fits this experiment better than an unpaired one.

Reference

Himes BE, Jiang X, Wagner P, et al. (2014). RNA-Seq transcriptome profiling identifies CRISPLD2 as a glucocorticoid responsive gene that modulates cytokine function in airway smooth muscle cells. PLoS ONE 9(6): e99625.
