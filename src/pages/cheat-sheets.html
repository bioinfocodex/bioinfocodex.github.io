Finding your way

pwdShow the current folder
ls -lhList files with readable sizes
cd data/rawMove into a folder
cd ..Go up one level
mkdir -p results/qcMake a folder and its parents
du -sh *Size of each item here
df -h .Free space on this disk

Looking inside files

head -n 8 reads.fastqFirst 8 lines (2 reads)
less -S file.tsvPage through without wrapping (q quits)
zcat reads.fastq.gz | headPeek inside a gzipped file
wc -l file.txtCount lines
grep -c "^>" seqs.fastaCount sequences in a FASTA file
cut -f1,3 table.tsvKeep columns 1 and 3
sort -k2,2nr table.tsvSort by column 2, largest first
sort file | uniq -cCount how often each line occurs

Combining commands

cmd1 | cmd2Send the output of one into the next
cmd > out.txtWrite output to a file (overwrites)
cmd >> out.txtAppend to a file
cmd 2> err.logSave error messages
cmd1 && cmd2Run the second only if the first worked
for f in *.fastq.gz; do echo "$f"; doneRepeat for every matching file

Easy to get wrong

  • Coordinates. BED starts counting at 0 and excludes the end; GTF, GFF3, SAM and VCF start at 1.
  • Chromosome names. chr1 (UCSC) and 1 (Ensembl) are not interchangeable. The genome and the annotation must use the same style.
  • Annotation release. Use the GTF from the same source and release as the genome FASTA.
  • Paired files. _1 and _2 (or R1 and R2) must stay in the same read order.

Quality scores (Phred)

Q101 error in 10 (90% accurate)
Q201 in 100 (99%)
Q301 in 1,000 (99.9%)
Q401 in 10,000 (99.99%)

Q = −10 × log10(probability the base is wrong).

An RNA-seq pipeline, command by command

Paired-end reads, alignment route. Explained step by step in Module 5; RNAflow writes these for your own samples.

# 1. Quality control of the raw reads fastqc -t 4 -o qc/ raw/*.fastq.gz multiqc qc/ -o qc/ # 2. Trim adapters and low-quality bases fastp -i raw/S1_1.fastq.gz -I raw/S1_2.fastq.gz \ -o trimmed/S1_1.fastq.gz -O trimmed/S1_2.fastq.gz \ --detect_adapter_for_pe -w 4 -h qc/S1_fastp.html -j qc/S1_fastp.json # 3. Index the genome (once per genome) hisat2-build -p 8 genome.fa index/genome # 4. Align, sort and index hisat2 -p 8 -x index/genome -1 trimmed/S1_1.fastq.gz -2 trimmed/S1_2.fastq.gz \ | samtools sort -@ 4 -o aligned/S1.bam - samtools index aligned/S1.bam samtools flagstat aligned/S1.bam # 5. Count read pairs per gene (-s 0 unstranded, 1 forward, 2 reverse) featureCounts -T 8 -p --countReadPairs -s 0 -a genes.gtf -o counts/counts.txt aligned/*.bam

Alignment-free alternative (Salmon)

salmon index -t transcripts.fa -i index/salmon salmon quant -i index/salmon -l A -p 8 --validateMappings \ -1 trimmed/S1_1.fastq.gz -2 trimmed/S1_2.fastq.gz -o quant/S1

Differential expression in R (DESeq2)

library(DESeq2) dds <- DESeqDataSetFromMatrix(countData = counts, colData = samples, design = ~ condition) dds <- dds[rowSums(counts(dds)) >= 10, ] dds <- DESeq(dds) resultsNames(dds) res <- lfcShrink(dds, coef = 2, type = "apeglm") sig <- subset(res, padj < 0.05 & abs(log2FoldChange) > 1)

What good output looks like

Bases at Q30 or betterabove 80%
Reads kept after trimmingabove 90%
Overall alignment rateabove 80% for a good reference
Reads assigned to genesroughly 60 to 80%
Replicates in the PCAgroup by condition

Typical values, not hard limits. A sample far from the others is the thing to look at.

Before you start

  • At least 3 biological replicates per condition.
  • Know whether the library is stranded; it changes the counting step.
  • Genome and annotation from the same source and release.
  • Write down every tool version. You will need them for the methods section.
