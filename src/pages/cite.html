How to cite RNAflow

Cite the archived software through its Zenodo DOI. Then cite the tools RNAflow ran for you, because they did the analysis.

The software

This DOI always resolves to the latest version. Each release also has its own DOI on Zenodo; use that one if you want to pin the exact version you ran.

Bhattarai, M. (2026). RNAflow: a guided desktop application for reproducible bulk RNA-seq analysis (Version %%RNAFLOW_VERSION%%) [Computer software]. Zenodo. https://doi.org/%%DOI%%

BibTeX

@software{bhattarai_rnaflow, author = {Bhattarai, Matrika}, title = {RNAflow: a guided desktop application for reproducible bulk RNA-seq analysis}, year = {2026}, version = {%%RNAFLOW_VERSION%%}, publisher = {Zenodo}, doi = {%%DOI%%}, url = {https://doi.org/%%DOI%%} }

GitHub's "Cite this repository" button on the RNAflow repository gives the same reference in other formats.

In your methods section

State the RNAflow version, then name each tool and version that produced your results. RNAflow writes these to results/software_versions.txt for every run. A typical sentence:

RNA-seq reads were processed with RNAflow v%%RNAFLOW_VERSION%% (Bhattarai, 2026). Reads were quality-checked with FastQC and trimmed with fastp, transcripts were quantified with Salmon, and differential expression was tested with DESeq2 using apeglm shrinkage of fold changes. Genes with adjusted p < 0.05 and |log2 fold change| > 1 were considered differentially expressed.

Change the sentence to match the route you took (for example HISAT2 and featureCounts in place of Salmon) and the thresholds you used.

Tools to cite alongside RNAflow

Cite the ones your analysis used. The interpreting results section of the manual has example methods text for the alignment route.

  • FastQC: quality control of raw reads
  • fastp: adapter and quality trimming
  • Salmon: transcript quantification
  • HISAT2: read alignment
  • featureCounts (Subread): read counting
  • DESeq2, edgeR, limma-voom: differential expression
  • apeglm: fold-change shrinkage
  • clusterProfiler, fgsea, MSigDB: enrichment analysis
  • MultiQC: summary reports
  • Ensembl: reference genome and annotation, with the release number

Citing the course

To cite a page of the course, give its title, "BioInfoCodex", the address and the date you read it.
